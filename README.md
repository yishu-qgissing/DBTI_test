# DBTI

DBTI 是一个受中国地下电影《DB》启发制作的非官方网页测试。它从影片人物面对金钱、工作、家庭、欲望与自我幻觉时的不同姿态出发，将角色的生存逻辑重新组织成一套带有黑色幽默的互动叙事。测试并非心理学量表，也不提供严肃的人格诊断；结果只用于娱乐、讨论与作品交流。

## 四个维度

四条轴描述的不是一个人“是什么”，而是当生活开始索债时，他更习惯用什么姿势活下去。每个维度都是连续光谱，没有天然正确的一端；测试也不会把人固定在某个字母里，只用它们寻找与影片角色相近的生存逻辑。

### D—B：梦想 / 面包（欲望锚点）

这一维询问：你用什么证明生活仍然值得继续？靠近 D 的人更愿意以理想、爱情、尊严或某种关于“我是谁”的叙事组织欲望，哪怕现实暂时无法兑现；靠近 B 的人则先确认资源、收入、机会和退路，认为不能落地的愿望很容易沦为自我安慰。梦想可能保存灵魂，也可能替无能遮羞；面包能够购买选择权，也可能让人只相信可结算的东西。

### R—P：抵抗 / 扮演（规则姿态）

这一维讨论人与规则的距离。靠近 R 的人倾向于质疑、拒绝或直接撞击秩序，即使反抗未必有效；靠近 P 的人更擅长识别规则、进入角色，并在制度允许的缝隙里交换资源和位置。抵抗不等于真正自由，它也可能只是拒绝承担后果；扮演不等于真心服从，它可能是活下去的技术，也可能在某一天变成自己曾经厌恶的权力。

### T—S：缠结 / 分离（关系模式）

这一维观察你如何理解亲密、忠诚和边界。靠近 T 的人容易把爱、金钱、照顾与亏欠绑在一起：付出意味着关系，关系也意味着交代；靠近 S 的人更强调个体边界，即使接纳、合作或相爱，也保留拒绝和退出的权利。缠结可以产生炽烈的忠诚，也会把赠予写成账本；分离能够保护善意不被侵占，也可能使亲密永远停留在安全距离之外。

### E—I：外化 / 内化（压力处理）

这一维关心痛苦最终被放到哪里。靠近 E 的人更可能把压力变成行动、争吵、表演、索取或对外部世界的指控，让冲突在现场发生；靠近 I 的人则倾向于分析、反刍、讽刺、自责或为经历寻找精神解释，让冲突在身体和意识内部继续。外化能让困境被看见，也可能伤害最近的人；内化能保存复杂性，却可能把清醒变成无法动身的理由。
