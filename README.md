# DBTI

DBTI 是一个受中国地下电影《DB》启发制作的非官方网页测试。它从影片人物面对金钱、工作、家庭、欲望与自我幻觉时的不同姿态出发，将角色的生存逻辑重新组织成一套带有黑色幽默的互动叙事。测试并非心理学量表，也不提供严肃的人格诊断；结果只用于娱乐、讨论与作品交流。

本项目为个人、非商业的影迷创作，与影片出品方、主创及相关权利人不存在官方合作、授权或背书关系。影片名称、人物及引用台词等相关权利归原权利人所有；项目不提供或传播影片正片，不以替代原作为目的。如权利人对内容展示有异议，请联系项目维护者，我们会及时核查并作出必要调整。
